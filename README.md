# Bridgit Nyambeka Portfolio

This is a small static portfolio website built with plain HTML, CSS and minimal vanilla JavaScript.

## Project structure

- `index.html` — all page content and section structure.
- `styles.css` — all design rules, spacing, colours, layout and responsive styling.
- `script.js` — tiny interactions for the mobile navigation and footer year.
- `assets/` — local images and project visuals.

## Quick edit guide

### Update personal information
Edit the text directly in `index.html`.

Important areas include:
- Hero intro and buttons.
- About section copy.
- Project titles and descriptions.
- Case study text and placeholders.
- Experience section.
- Contact details and links.

### Update colours and global styling
Adjust the CSS variables in `styles.css` near the top of the file.

### Replace images
Add or replace files in the `assets/` folders.

Use the existing file paths or update the `src` values in `index.html` when new files are added.

### Keep the project easy to maintain
The page is intentionally simple and readable. Most content is written directly in the HTML so it can be edited without a build step or framework.

## Notes

- The design follows a minimal editorial style with a strong green, ivory and taupe palette.
- Placeholder content is used where assets or verified metrics are not yet available.
- The page works as a static website and can be opened directly in a browser.
